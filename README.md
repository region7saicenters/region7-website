# Region 7 Sai Centers website preview

This repository is a public preview of the redesigned Region 7 Sai Centers website. It is not the live site.

The live public site remains at [region7saicenters.org/region7new](https://region7saicenters.org/region7new/). Nothing in this preview changes that site.

## About this preview

Region 7 covers Sathya Sai Centers and Groups in the San Francisco Bay Area, Northern California, and Nevada. This preview shows a proposed redesign for review. Page links use `.html` paths so the site works on GitHub Pages (for example, `about.html` and `programs.html`).
